This feature is stopped until you configure a dedicated hostname and its DNS-only record. It never changes DNS automatically.

Network setup required: on a router with a public WAN address, forward external TCP 80 to this device's port 8080 and external TCP 443 to its port 443. The existing LAN proxy already uses port 80 on the Wi-Fi address, so this proxy avoids that port. Router configuration, ISP inbound rules, and Android battery policy cannot be changed from Termux. Do not expose port 8000 directly.
Public visitors would reach the existing authenticated file manager, including its file-management controls. HTTPS preserves the existing password challenge; use a strong unique server password. Direct Hosting does not weaken authentication.
