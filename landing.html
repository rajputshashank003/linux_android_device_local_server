What you can do

A practical workspace for your files

Useful tools for organizing, understanding, and accessing your personal files.

File management

Browse folders, search, sort, rename, move, and organize your files.

Upload and download

Transfer files through the authenticated web interface, including multi-file uploads.

Online previews

Preview supported documents, images, audio, and video directly in the browser.

AI file assistance

Ask questions about supported files and use document-aware assistance when configured.

Agentic Chat

Use a dedicated assistant interface with saved conversations and selected file attachments.

Local AI options

Connect supported local models, with optional remote-provider integration available separately.

Live chat

Signed-in users can communicate through the server’s real-time chat feature.

Health monitoring

Review backend, database, model, storage, and resource status in the private dashboard.

Protected file access

Sign-in is enforced by the server for private files and administration, with path checks on file operations.

Built for ownership

Your workspace, on infrastructure you control.

MyFile is designed to run on the owner’s own machine. The public website is an introduction; file access and administration remain behind the existing server authentication.

✓
Self-managed serverThe core application is a Python server designed to run locally, including on Termux.
✓
Local persistenceApplication records use a local SQLite database; files remain in the configured local storage directory.
✓
Optional AI providersLocal inference and OpenRouter are separate choices; external processing is used only when selected.
